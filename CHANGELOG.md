# Changelog

## 1.0.1

### English

- Add compatibility with White Knuckle The Core 0.70b and Simple Multi Player 1.8.7.
- Improve model synchronization when first joining a lobby, switching models, and reconnecting.
- Fix an issue that could delay remote crouch and stand updates by about 10 seconds.
- Fix an issue where Rossi sometimes appeared as `Custom model 1` after extraction by r2modman.

### 简体中文

- 适配 White Knuckle The Core 0.70b 与 Simple Multi Player 1.8.7。
- 改善首次入房、切换模型和重连后的模型同步。
- 修复远端蹲下和站起可能延迟约 10 秒的问题。
- 修复 r2modman 解包后，洛茜有时显示为 `Custom model 1` 的问题。
