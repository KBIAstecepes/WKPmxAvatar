# 实现与排查

Bootstrap 绑定配置和兼容补丁，Models 解析 PMX 并建立外观；Compatibility 与 UI 负责模型身份及大厅选择。网络只同步选择标识，模型按 PMX 内容哈希识别，资源缺失时回退。

Animation 根据真实位移及游戏状态驱动动作，再叠加下蹲、观察和接触。Interaction 负责接触求解及独立的身体抓取体积对齐。Grips 使用网格空间/根空间姿态和物品可视副本，Physics 为固定长度裙摆姿态让位及次级动态链。Rendering 处理材质和静态面眼协调；Hands 是独立第一人称图层替换；Gaze/DevTools 仅用于开发。

OriginalMotionPreview 和 InteractionPosePreview 仍有正式运行职责，不能按名称删除。每帧先恢复上一帧握持附加变换，再采样动作/接触；捕获基础姿态后叠加预制握持并同步物品。改变顺序可能让修正累积。关闭或销毁时恢复原渲染/抓取状态并释放自建资源。

衣物不得反向带动腿部运动，也不应靠拉长裙子或过大的空气间距掩盖穿插。原作动作适配服从 White Knuckle 实际运动，不改变加速、落地或转向来播放完整片段。

排查顺序：唯一插件加载与依赖接口 → 模型与贴图 → 动作/嵌入配置 → 物品名、左右与坐标空间 → 材质和正式开关 → 离房/切模型恢复。R001 为多人接口，R003 为模型/贴图，R010 为动作回退，R011/R012 为握持回退，R015 为可选手图。保留必要脱敏错误提示，避免公开个人路径与身份。

源码和工具不是原模型/原作资源许可证的替代。公共披露前仍需核对源码中的拟合参数及第三方来源，见第三方通知。
