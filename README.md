## 开发

阅读 [构建说明](docs/BUILD.md)，准备具有使用依据的本地引用和配置输入，然后运行 Build.ps1。缺少本地输入时应停止，不使用空配置伪造可用结果。完整模型导入与资源再生成工具仍在本地维护工作区，尚未全部纳入此代码仓库。

| 构建 | 内容 |
|---|---|
| PublicRelease | 正式运行逻辑；不含开发调试入口和自动眼动 |
| Development | 同一核心实现，保留 F8 等调试、观察与眼动研究能力 |

两种插件不能在同一游戏实例同时加载。构建不安装、不启动游戏、不上传文件。

## 功能与限制

提供 PMX 外观加载、模型选择与多人外观同步、动作适配、下蹲与接触、第三人称握持、裙摆和次级运动，以及可选第一人称手图/狼爪提示。洛茜专属能力不代表任意 PMX 均已适配。模型文件不通过网络传输，其他玩家需有匹配的本地资源。

当前保留认可的角色光照外观；环境光响应问题后续修复，不能宣称已完全生效。自动眼动只保留在开发版。历史离线数值验证不等于所有游戏环境实机通过。
